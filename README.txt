인천상의 오피스 사용법

1. 압축 파일을 통째로 풀어주세요. (압축 안에서 바로 실행하면 안 됩니다)
2. run_IncheonOffice.bat 를 더블클릭하면 버튼 창이 뜹니다.
   - 한글이 꺼져 있으면 같이 켜집니다.
   - 처음 실행하면 같은 폴더에 "인천상의 오피스" 바로가기(로고 아이콘)가 생깁니다.
3. 버튼 창 아래에 "● 한글 연결됨"이 보이면 준비 완료입니다.

[탭 구성]
 문서      : 양식 열기(업무보고·공문·보도자료·여비계산서·법인카드·시간외근로·수료증), 보고서, 간부회의 자료, 예산코드 찾기
 글자      : 기본 정리, 개조식 기호, 항목 번호·자동 입력, 들여쓰기, 크기·색, 글꼴, 특수문자
 표        : 인천상의 표, 표 모양, 테두리·배경색, 행·열·셀, 계산·단위, 내용·변환
 정리      : 줄 정리, 정렬, 숫자·금액, 주민번호·전화번호·나이, 형광펜, 마크다운, 날짜
 이동      : 페이지, 색깔 글자·숫자·날짜 찾기, 쪽번호
 편리      : 메일머지, 목차, 참석자 명단, 공문 언어 순화, 메모, 용량 줄여 저장, 업데이트 확인
 인천광역시: 인천시 보고서 틀 7종, 인천시 양식, 부품, 기호 (인천시 양식 그대로)

[알아두실 점]
- 새 버전이 나오면 프로그램을 켤 때 알림이 뜹니다. [예]를 누르면 알아서 바뀌고 다시 켜집니다.
  (내 정보·내 서식은 그대로 남습니다. [편리] 탭 [업데이트 확인]으로 직접 확인할 수도 있습니다)
- 버튼에 마우스를 올리면 창 아래에 설명이 나옵니다.
- 이름 끝에 ▸ 가 붙은 버튼은 작은 창이 뜹니다.
- 한글이 "접근 허용" 창을 띄우면 [모두 허용] 또는 [허용]을 눌러주세요.
- 양식 열기와 수료증은 원본을 건드리지 않고 내 문서\인천상의 문서 폴더에 복사본을 만듭니다.
- 오류가 나면 app 폴더의 log.txt 파일을 보내주세요.
- 아직 들어 있지 않은 것: 기본서식탭 검토분, 단축키, 품의서 기능(보류), 셀 너비 자동 조절
